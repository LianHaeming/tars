# Burmese phonetic style guide

One respelling for every Burmese sentence in the app, readable aloud by an English speaker. It follows how the words
are **pronounced in casual speech**, not how they are spelled, and it never changes: the same sound is always written
the same way, because answers are scored by spelling closeness.

## Shape
- Lowercase only. Syllables inside a word are joined with hyphens, words are separated by single spaces:
  `chay-zu tin-ba-deh`.
- No tone marks, no IPA, no apostrophes, no capitals, no punctuation except a final `?` on questions.
- Write the voicing that happens in connected speech: `ba` not `pa` for ပါ after a syllable, `deh` not `teh` for တယ်,
  `ga` not `ka` for က after a syllable. The one exception is သ, which is always `th`.

## Vowels (open syllables)
| Write | Sounds like | Example |
|---|---|---|
| a | a in "father" | `ma` |
| i | ee in "see" | `mi` |
| u | oo in "food" | `thu` |
| ay | ay in "day" | `lay` |
| eh | e in "bed" | `deh` |
| aw | aw in "saw" | `kaw` |
| o | o in "go" | `lo` |

| un | oon in "soon", short (nasal) | `lun` |
| oun | own in "own" (nasal) | `koun` |

| eik | ake in "make", cut off | `eik` |

## Consonants
| Write | Burmese | Sounds like |
|---|---|---|
| k / kh / g / ng | က / ခ / ဂ / င | k (soft) / k with a puff / g / ng in "sing", also at the start (`nga`) |
| s / hs / z | စ / ဆ / ဇ | s / s with a puff / z |
| t / ht / d | တ / ထ / ဒ | t (soft) / t with a puff / d |
| p / hp / b | ပ / ဖ / ဗ | p (soft) / p with a puff / b |
| th | သ | th in "think" (or "this" — always written `th`) |
| ch | ကျ, ချ | ch in "church" |
| j | ဂျ | j in "jam" |
| y | ယ, ရ, medial ြ / ျ | y in "yes" (`pya`, `mya`) |
| sh | ရှ, သျှ | sh |
| hm / hn / hl / hny | မှ / နှ / လှ / ညှ | breathy m / n / l / ny |
| ny | ည | ny in "canyon" |
| m n l w h | မ န လ ဝ ဟ | as in English |

## Speaker
Every sentence is Lian (a man) talking casually to his boyfriend or friends: `nga` for I, `min` for you, casual
endings (`deh`, `la`, `ba`), polite `khin-mya` only if a sentence really needs it.

## Examples
- Thank you → `chay-zu tin-ba-deh`
- Are you hungry? → `baik hsa-la?`
- This is delicious! → `di-ha sa-lo kaung-deh`
